Compiler Generation eXplorer

コンパイラの挙動を分析する
条件:
	GCC, Clang
	O0, O2, O3
	x86, arm, riscv
それぞれの条件下で生成されたasmを分析して、コンパイラの挙動を観察する
これによってどのようなコードと条件が最適かについて等、考察できるものがあると考えられる

対象OSはLinuxで統一
マイコン向けではなくPC向けの最適化を見る

CGX:
	runner: linux
	analyzer: windows

CGX-data:
	write: linux
	read: windows


x86_64:			x86_64-linux-gnu-gcc / clang
ARM(AArch64):	aarch64-linux-gnu-gcc / clang --target=aarch64-linux-gnu
RISC-V (RV64):	riscv64-linux-gnu-gcc / clang --target=riscv64-linux-gnu
